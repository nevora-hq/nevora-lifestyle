各題材は既存の題材(冷蔵庫定位置、黒カビ順番、生乾き臭、電気代順番、エアコンフィルター、寝室の光・温度、衣替え防虫、作り置き、台所動線、結露、備蓄、排水口、除湿機、米保存、ヒートショック、寝だめ ほか)と、悩みの場面が別になるよう選んだ。近い項目は各題材の「避ける点」に書いた。

## 1. 家事・時短
- 仮の題: 朝バタバタを減らす、夜のうちに済ませておく家事の決め方
- メインの語: 朝 バタバタ 夜のうちに
- 関連語: 朝の支度 段取り / 朝 家事 減らす / 前日の夜 やっておくこと / 朝 時間がない
- 読者の場面: 朝、出かける前に洗濯・弁当・身支度が重なり、毎日時間が足りずに焦る。夜に何を前倒しすればよいか分からない。
- 避ける点: 「家事時間の内訳」(時間の全体像)とは別。朝の場面に絞り、夜にやる項目の選び方を扱う。
- 想定記事タイプ: 集客

## 2. 掃除
- 仮の題: 換気扇・レンジフードの掃除を大掃除前に始める順番と、無理に外さない範囲
- メインの語: 換気扇 掃除 大掃除 前倒し
- 関連語: レンジフード 掃除 手順 / 換気扇 油汚れ 年末前 / フィルター 外し方 / 換気扇 どこまで掃除
- 読者の場面: 年末にまとめてやるのはつらいので11月のうちに始めたいが、油が固まっていて、どこまで分解してよいか分からない。
- 避ける点: 「洗剤を増やしても落ちない」とは別。洗剤の話でなく、始める時期・手順・外してよい範囲の線引きに絞る。
- 想定記事タイプ: 集客

## 3. 洗濯
- 仮の題: 毛布は家の洗濯機で洗える？洗う前の確認と干し方
- メインの語: 毛布 洗濯 自宅
- 関連語: 毛布 洗濯機 入らない / 毛布 洗い方 ネット / 毛布 乾かし方 / 毛布 コインランドリー 家で どっち
- 読者の場面: 寒くなって毛布を出したが、においが気になる。洗濯表示や洗濯機の大きさで洗えるか分からず、乾かし方も不安。
- 避ける点: 「タオル生乾き臭」とは別。大物(毛布)の洗う・乾かす判断。
- 想定記事タイプ: 集客

## 4. 収納・片づけ
- 仮の題: 玄関にコートが溜まる家の、上着の置き場所の決め方
- メインの語: 玄関 コート 収納
- 関連語: 玄関 上着 置き場 / コート かける場所 帰宅後 / 玄関 マフラー 手袋 収納 / 上着 リビング 散らかる
- 読者の場面: 寒くなって上着が増え、帰宅後にソファや椅子の背に掛けっぱなしになる。玄関に置き場がなく、片づけが続かない。
- 避ける点: 「衣替え防虫」「収納の高さと防災」とは別。帰宅後の動線上の置き場に絞る。
- 想定記事タイプ: 集客

## 5. 節約・家計
- 仮の題: 冬にガス代が上がる理由と、お湯の使い方で変えられるところ
- メインの語: ガス代 冬 上がる
- 関連語: ガス代 節約 お風呂 / 追い焚き シャワー どっち / 給湯 設定温度 冬 / ガス代 高い 原因
- 読者の場面: 秋から冬にかけてガス代の請求が増えて驚いた。風呂とシャワーのどちらが得か、何を変えればよいか分からない。
- 避ける点: 「電気代を下げる順番」とは別(ガス・お湯が対象)。「ヒートショック入浴手順」の安全面とは混ぜない。
- 想定記事タイプ: 集客(のちに比較・収益へ展開しやすい)

## 6. 食・料理
- 仮の題: きのこは洗わず冷凍するのが正解？買いすぎた時の保存のしかた
- メインの語: きのこ 冷凍 保存
- 関連語: きのこ 洗う 洗わない / しいたけ 冷凍 / きのこ 傷む 見分け / きのこ 冷凍 そのまま 調理
- 読者の場面: 秋にきのこが安く、買いすぎて使い切れない。洗うか、石づきを取るか、冷凍後にどう使うかで迷う。
- 避ける点: 「冷蔵庫の定位置」「作り置き」「米の保存容器」とは別の、食材1種の下ごしらえと保存に絞る。
- 想定記事タイプ: 集客

## 7. 住まい・インテリア
- 仮の題: 床からの底冷えを、ラグと敷き方で和らげる考え方
- メインの語: 底冷え 床 対策
- 関連語: フローリング 寒い ラグ / 足元 冷える 部屋 / 床 断熱 ジョイントマット / 1階 寒い 床
- 読者の場面: 暖房をつけても足元だけ冷える。ラグを敷くべきか、何を下に敷けば違いが出るか分からない。
- 避ける点: 「窓の結露」「寝室の光と温度」とは別。窓でなく床まわりに絞る。
- 想定記事タイプ: 集客

## 8. 生活家電
- 仮の題: 加湿器を出したら最初にやること。においとカビを防ぐ手入れの回数
- メインの語: 加湿器 手入れ 使い始め
- 関連語: 加湿器 掃除 頻度 / 加湿器 臭い / 加湿器 水 毎日 替える / 加湿器 クエン酸
- 読者の場面: 去年しまった加湿器を出したら、タンクが臭う。どこまで洗えばよいか、毎日何をすればよいか分からない。
- 避ける点: 「除湿機の方式」「エアコンフィルター」とは別の家電。方式の比較でなく手入れに絞る。
- 想定記事タイプ: 集客

## 9. 暮らしの知恵
- 仮の題: 冬のパチパチ静電気を減らす、ドアノブ・服・髪の場面別の工夫
- メインの語: 静電気 対策 冬
- 関連語: 静電気 ドアノブ 痛い / 静電気 服 まとわりつく / 静電気 起きにくい 素材 / 静電気 部屋 湿度
- 読者の場面: 乾燥する季節に、ドアノブや車のドアで毎回バチッとなる。服のまとわりも不快で、何から変えればよいか分からない。
- 避ける点: 「結露は湿度で止める」の湿度の話と混ぜず、静電気が起きる場面ごとの対処に絞る。髪・肌の話は健康・美容に寄るため扱わない。
- 想定記事タイプ: 集客

## 10. 睡眠・休息
- 仮の題: 寝る前にスマホを見てしまう人の、置き場所と充電場所の決め方
- メインの語: 寝る前 スマホ 置き場所
- 関連語: 寝室 スマホ 充電 / 寝る前 スマホ やめたい / スマホ ベッド 持ち込まない / 目覚まし スマホ 離す
- 読者の場面: 布団に入ってもつい見続けて寝る時間が遅くなる。意志に頼らず、置き場所で変えられないか知りたい。
- 避ける点: 「寝室環境と朝の光」「寝室の光と温度」「休日の寝だめ」とは別(行動・置き場の話)。不眠や症状の話には踏み込まない。
- 想定記事タイプ: 集客
