# 記事データ受け渡しフォルダ

サブエージェント(ライター・編集長)が作成し、編集長が100点満点で承認した確定稿を、
サイト本体(Next.js)へ公開するための受け渡し場所です。

## 運用ルール

- ライターは執筆中の下書きを `下書き\` にMarkdownで保存する(frontmatterにtitle/category/tags/affiliateLinks等を含める)
- 編集長が承認した最終稿(公開可否100点)は `確定稿\` にMarkdownで保存する
  - ファイル名: `YYYY-MM-DD_テーマ.md`
- 配信者が確定稿を `サイト本体\` 配下のcontentディレクトリへ配置し、Git commit・pushする(Vercelが自動デプロイ)
- 公開が完了した確定稿は `公開済み\` へ移動する
