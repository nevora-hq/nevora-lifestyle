# frontmatter体験示唆表現 監査結果

対象: `サイト運営/記事データ/確定稿/` `サイト運営/記事データ/公開済み/` 配下 全.md(下書きは対象外)
方法: キーワードGrep(体験談を/実際に使ってみた/使ってみたところ/試してみた/効果を感じた/効果を実感した/編集部が実際に/編集部で試した/編集部の体験/してみた結果/してわかったこと/して気づいたこと/使用してみて/使い続けてみて/検証してみた)でヒットしたファイルのfrontmatter範囲を目視確認。
※本文(frontmatter外)側のみでヒットした箇所はfrontmatter対象外のため一覧から除外。

## 一覧

判定の区分:

- **矛盾あり**: frontmatter(description・accordions の summary など)で体験談を予告しているのに、本文に体験談が無い(一般論のみ)。優先修正対象
- **矛盾なし・本文側にB5違反の疑い**: 予告に対応する体験談が本文にあるが、それが一人称の体験談である(B5違反が本文側に残っている可能性)
- **第三者の体験談**: 本文に対応する第三者(友人など)のエピソードがある。一人称ではないのでB5(一人称体験談)には該当しない可能性が高いが、参考情報として記載する
- **要確認**: 「まずは手持ちの洗剤で試してみたい」「1回で落ちるか試してみたい」など、読者の意向・読者視点の表現。サイト側の実施・体験を主張するものではなく、B5には該当しない可能性が高いが念のため記載する
- **対象フィールド外**: 対象外のフィールド(question など)でのヒットは、参考記載のみ
