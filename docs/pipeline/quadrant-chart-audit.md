# quadrantチャート誤読リスク監査

対象: `type: "quadrant"`チャートを持つ全記事(公開済み)。対象記事を洗い出して、下の表に記録する。

背景: Y軸(費用感、値が高いほど高額=悪い)の高い方に◎がつくと「費用面で優れている」と誤読されるリスクがある。`lib/posts.js`の`renderQuadrantChartHtml`を修正し、◎○△の評価記号を廃止して中立的な高低表現(「高い/中程度/低い」)をデフォルトにした(CONTRIBUTING.md §20参照)。この変更により記号由来の誤読リスクは全記事で自動的に解消する。

以下は、軸の意味が「高い=悪い(費用・価格・電気代など)」であるためレンダラー修正後も文言(「高い/中程度/低い」)だけでは実感に合わない可能性がある記事を一覧にする欄。**修正はユーザーの確認後に行う(本監査は報告のみ)。**

## 誤読リスクあり(費用・価格軸で「高い=悪い」の意味を持つ)

確かめ方:
- チャートが`note`フィールドを持つ場合は、レンダラーの中立化(「高い/中程度/低い」)が適用され、評価の含意を持つ記号は残らない。個別の`xNote`/`yNote`(例:「約〇円/年」等の具体的な文言)を足すとより親切だが、誤読リスクの観点では必須ではない
- `note`ではなく`source`のみを持つ場合は、フォールバック表に**座標の生数値がそのまま表示される**。◎○△由来の誤読は起きないが、「座標値をそのまま数値で見せると測定値であるかのような誤解を招く」というquadrant設計時の懸念には抵触したままで、別種の課題として残る(優先度: 低、`note`追加の要否も含めユーザー判断)

## 誤読リスク低(軸の値が高い=良い、またはニュートラルな属性)

両軸とも「値が高い=一般に好ましい、または単なる特性の強弱(良し悪しの評価を伴わない)」である記事は、記号除去・中立表現化により誤読リスクは実質的に解消しているので、追加対応は不要。軸ラベルに「低い←→高い」などの方向の注記があれば足りる。ここには記事名と両軸の名前を並べる(例: 汚れの落ちやすさ/手間の少なさ)。

## まとめ

- 記号(◎○△)由来の誤読リスクはレンダラーの修正で解消する(記事側の追加修正は不要)。
- 費用・価格軸を持つ記事は、`xNote`/`yNote`で具体的な文言を足す候補として、優先度をつけて残す(軸ラベル自体に方向の説明がある記事は優先度低)。
